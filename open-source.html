Open source

The public repositories

Three tools from my own build pipeline, released under MIT, plus written case studies for three products. I specified each one and reviewed what the agents built; all of it lives at github.com/iskra-astudillo.

Tools

  • bugclass-detectors

    Static checks · CI gate · v0.1.0 · MIT · Python standard library

    A parser-based scanner for five silent-failure bug classes that AI-written code keeps reintroducing: swallowed write errors, undefined names on rare paths, inline secrets, safety flags that fail open, and secrets captured once and never re-read. Grep could not find these reliably, so it reads the syntax tree instead. A high finding fails the build. Hosted version at bugclass.eliteaiempire.com.

  • answerbeacon-check

    CLI + MCP server · v0.1.0 · MIT · Python standard library

    Scores a web page on twenty elements that AI search engines read, shows the evidence, and writes the fix for each miss. It also runs as a server so an AI agent can call it. The first real run was against my own company site, and the fixes it wrote shipped the same day.

  • rulesmith

    Config generator · v0.1.0 · MIT · Python standard library

    Write AI coding rules once and generate the rule files that each coding tool expects, then fail CI when they drift apart. One source of truth for the rules, whatever tool each engineer or agent uses. Hosted at rulesmith.eliteaiempire.com.

Case studies

Each documents the problem, the design and the engineering decisions, under a CC BY 4.0 licence. They are the three places a hiring team can read my design reasoning without a meeting.

  • governed-agents-case-study

    CC BY 4.0

    AI agents a business can audit: permission per action, a person approves anything irreversible, every action on a hash-chained record, budgets as hard limits, fail closed. The product is Elite Agentic Solutions; the same principles run my own build pipeline.

  • cohostbnb-case-study

    CC BY 4.0

    An operations workspace for short-term rentals and small lodging: guest replies, room preparation and maintenance in one place, with AI drafts a person approves before anything reaches a guest. Drawn from fifteen years of answering those messages myself.

  • clipwright-case-study

    CC BY 4.0

    A video clipping service that checks rights before it processes anything. It refuses by default, accepts uploads and never links, shows why each moment was picked, and publishes one clip at a time to the user's own account.
